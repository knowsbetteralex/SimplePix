# SimplePix

Простой нативный Android-редактор для быстрых коллажей.

## Что уже умеет MVP

- добавлять одну или сразу несколько фотографий;
- выбирать слой касанием;
- перетаскивать слои одним пальцем;
- масштабировать pinch-жестом;
- поворачивать двумя пальцами;
- менять порядок слоёв;
- добавлять текст;
- менять цвет фона;
- вырезать части выбранной фотографии ластиком;
- удалять выбранный слой;
- сохранять готовый коллаж в PNG в `Pictures/SimplePix`.

## Управление

1. Нажмите **Фото** и выберите изображения.
2. Коснитесь нужного слоя.
3. Один палец — перемещение.
4. Два пальца — масштаб и поворот.
5. **Ластик** работает только с выбранной фотографией.
6. **Ниже / Выше** меняют порядок слоёв.
7. **Сохранить** экспортирует PNG.

## Техническая база

- Java;
- Android SDK без Compose;
- без сторонних UI-библиотек;
- минимальная версия Android 10 (API 29);
- слои и жесты реализованы в собственном `CollageView`.

## Ближайшие улучшения

- undo/redo;
- регулируемый размер ластика;
- прямоугольное и свободное кадрирование;
- цвет/шрифт/обводка текста;
- произвольный выбор цвета;
- прозрачный фон;
- изменение размера и соотношения сторон холста;
- сохранение проекта со слоями;
- дублирование слоя;
- привязки и направляющие;
- экспорт в JPEG/WebP;
- более аккуратная панель инструментов и иконка приложения.

## Сборка

Проект открывается в Android Studio как обычный Gradle-проект.

GitHub Actions также собирает debug APK и публикует его как artifact **SimplePix-debug**.
