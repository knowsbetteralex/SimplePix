# SimplePix

Простой нативный Android-редактор для быстрых коллажей.

## Что уже умеет

- добавлять одну или сразу несколько фотографий;
- выбирать слой касанием;
- перетаскивать слои одним пальцем;
- масштабировать pinch-жестом;
- поворачивать двумя пальцами;
- менять порядок слоёв;
- undo / redo до 25 шагов;
- добавлять и редактировать текст;
- менять размер текста;
- включать жирный и курсив;
- выбирать произвольный RGB-цвет текста;
- выбирать произвольный RGB-цвет фона;
- вырезать части выбранной фотографии ластиком;
- менять размер ластика;
- делать центральную обрезку фото в форматах 1:1, 4:5, 3:4, 16:9 и 9:16;
- быстро срезать по 5% с каждого края;
- выбирать формат холста: экран, 1:1, 4:5, 3:4, 9:16, 16:9 и A4;
- удалять выбранный слой;
- сохранять готовый коллаж в PNG в `Pictures/SimplePix`.

## Интерфейс

Верхняя панель:
- **↶ / ↷** — undo / redo;
- **Сохранить** — экспорт PNG.

Нижняя панель:
- **Фото** — добавить одно или несколько изображений;
- **Текст** — добавить текст, а при выбранном текстовом слое — изменить его;
- **Обрезка** — центральная обрезка выбранной фотографии;
- **Ластик** — ручное удаление пикселей выбранного фото;
- **Фон** — RGB-палитра фона;
- **Холст** — соотношение сторон результата;
- **Ниже / Выше** — порядок слоёв;
- **Удалить** — удалить выбранный слой.

## Управление жестами

1. Коснитесь слоя, чтобы выбрать его.
2. Один палец — перемещение.
3. Два пальца — масштаб и поворот.
4. При включённом ластике проведите пальцем по выбранной фотографии.
5. Белая рамка показывает выбранный слой и в экспорт не попадает.

## Техническая база

- Java;
- Android SDK без Compose;
- без сторонних UI-библиотек;
- минимальная версия Android 10 (API 29);
- слои, история действий, жесты и экспорт реализованы в собственном `CollageView`.

История хранит геометрию и ссылки на версии bitmap, а новую копию пикселей создаёт только перед разрушающим редактированием ластиком. Это заметно экономнее, чем копировать все изображения на каждый шаг undo.

## Следующие улучшения

- интерактивная рамка crop с перетаскиваемыми границами;
- свободное кадрирование;
- кисть/заливка по изображению;
- обводка, фон и выравнивание текста;
- выбор шрифтов;
- прозрачный фон;
- сохранение проекта со слоями;
- дублирование слоя;
- привязки, направляющие и центрирование;
- экспорт в JPEG/WebP;
- выбор разрешения экспорта;
- иконка приложения и стартовый экран.

## Сборка

Проект открывается в Android Studio как обычный Gradle-проект.

GitHub Actions собирает debug APK и публикует его как artifact **SimplePix-debug**.
